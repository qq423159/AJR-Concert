# Virtual Concert ❤️

A GitHub Pages concert website.

## Add your music
Put your MP3 files in the `music` folder:
- song1.mp3
- song2.mp3
- song3.mp3
- song4.mp3

Then edit the `songs` array near the top of `script.js`.

## Customize
Edit `wifeName` in `script.js`.

## GitHub Pages
1. Upload all files/folders to a GitHub repository.
2. Go to Settings → Pages.
3. Choose Deploy from branch.
4. Select `main` and `/ (root)`.
5. Save.

Note: browsers generally require a user click before audio can play, which is why the site has an ENTER CONCERT button.
